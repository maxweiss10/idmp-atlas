    How to read this site

    • Drug names open dosing in a side panel; the page you came from stays put.
    • The prescription line above each regimen takes doses from that drug's own IDMP table and says so. The original cell is always underneath.
    • ID-R UCSF and ID-R ZSFG mark restricted agents. UCSF login marks Box or SharePoint documents.
    • Set your hospital and patient once in the context button; every page reorders itself.
    • Press ⌘K or / to ask from anywhere.
