How to read this site

  • Drug names open a dosing drawer; the page you came from stays put.
  • The prescription line above each regimen pulls doses from the drug's own IDMP dosing table and says so; the original cell is always underneath.
  • ID-R · UCSF and ID-R · ZSFG mark ID-restricted agents; UCSF login marks Box/SharePoint documents.
  • Press ⌘K or / to ask from anywhere; ☆ pins a page to this list.
